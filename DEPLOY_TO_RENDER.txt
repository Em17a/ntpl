Nightplay Render 部署步骤

1. 解压 ZIP，把全部文件和文件夹上传到 GitHub 仓库根目录。
2. Render Dashboard → New → Blueprint。
3. 连接 GitHub 并选择仓库。
4. 检查 Blueprint 预览：Web Service `nightplay` + PostgreSQL `nightplay-db`，区域 Singapore。
5. 点击 Apply，等待构建和部署。
6. 打开 Render 提供的 HTTPS 地址；健康检查路径 `/api/health`。

重要：上传解压后的源码，不是只上传 ZIP。Render 需要从 GitHub 仓库根目录读取 render.yaml。
部署成功后请用两台设备测试房间、聊天和语音。语音在部分网络下可能需要 TURN 服务。
